## Menu

Komponenta `Navbar_2024-12`, jedna pro celý web.

Nové odkazy, zatím s českým textem:

- Atypické výstrče
- Atypické zámečnické konstrukce
- Designové obrazy

Odkaz **LED obrazovky** je v české verzi skrytý. Skryj ho i v EN a DE.

Těmhle odkazům chybí v EN a DE prefix `/en/` resp. `/de/`:

| Odkaz | URL, která tam je |
|---|---|
| Atypické výstrče | `/produkty/vystrce-lekarenske-znaky#atypicke-vystrce` |
| Atypické zámečnické konstrukce | `/produkty/zamecnicke-konstrukce-na-miru-opracovani-plexiskla#atypicke-zamecnicke-konstrukce` |
| Designové obrazy | `/produkty/velkoformatovy-tisk#designove-obrazy` |
| Polepy | `/produkty/velkoformatovy-tisk#dalsi-druhy-polepu` |
| odkaz s prázdným textem | `/produkty/3d-napisy-loga-a-jednotliva-pismena#profil-9` |
| Výstrče a lékárenské znaky (kategorie, jen EN) | `/produkty/vystrce-lekarenske-znaky` |

## URL

Slug ani kotva za `#` se nepřekládají. Mění se jen prefix na `/en/`
resp. `/de/`.
